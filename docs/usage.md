# 桌面使用指南

首次安装见[项目 README](../README.md#安装与开始使用)。本页介绍 VS Code 中的日常操作；手机操作见 [Telegram 指南](telegram.md#日常使用)。

## 对话与编辑器上下文

打开并信任项目文件夹，点击活动栏 **π**。显式点击「新建会话」开始新对话，或从历史列表恢复已有会话。

- Enter 发送，Shift+Enter 换行。
- 编辑器右键 **Pi: Add Selection to Chat** 附加选区；快捷键为 Linux / Windows 的 Ctrl+Alt+P、macOS 的 Cmd+Alt+P。也可附加文件或粘贴图片，实际图片支持取决于 Agent 能力。
- `piAcp.maxContextChars` 控制单个选区或文件附件的字符上限，默认 60000。
- 模型输出显示在滚动消息流中；连续工具调用与思考默认归为折叠组，结束后整轮过程自动折叠，保留最终回答。`piAcp.showThoughts` 控制思考内容的显示。
- 工具授权可在桌面或 Telegram 任一端处理；停止任务不会撤销工具已完成的文件修改。

## 会话与历史

运行中可以新建对话、切换历史会话或 Agent（Harness），已经提交的任务由服务继续执行。切回会话可查看进度、处理授权或停止任务；关闭 VS Code 也不会中断任务。

历史列表可滚动访问全部会话，显示高度可在约 4 / 10 / 16 条之间切换；选择会话、刷新或发送不会自动关闭列表。对话支持 Markdown 导出，导出会读取完整历史，不限于当前可见窗口。Pi 支持基于原生历史创建会话分支。

> 「清空历史」会删除当前服务器账户的共享历史，并停止全部 Agent 的会话任务，包括 Telegram 任务；界面会二次确认。只想停止当前任务时使用停止按钮。`piAcp.persistHistory` 只控制当前客户端的历史显示，服务仍会持久化任务。

默认共享历史位于服务账户的 `~/.pi/pi-acp-workbench/history/`。恢复依赖原生会话文件，备份时需同时保留 Agent 原生历史；服务故障后不会自动重放提示词或工具。

## 顶部待办清单

安装 `@juicesharp/rpiv-todo` 后，扩展创建的 todo 会显示在聊天区顶部的悬浮卡片中。卡片固定在消息滚动区域之外，展开历史列表时会随布局向下移动，不遮挡历史或消息。

- 每项显示状态圆圈；进行中以高亮圆点标识，完成后在圈内打钩并划去文字。
- 点击标题折叠 / 展开，折叠偏好随界面保存。
- 最多同时显示 5 项，更多项目通过列表内部滚动查看；长标题省略显示，悬停查看全文。
- 空清单自动隐藏，删除项不显示；已完成项保留可见。
- 清单状态随当前会话保存，恢复冷会话无需先启动 Pi。更新适配器后需重启会话服务，已有 worker 才会加载新的 RPC 桥接逻辑。

## 修改审阅

每轮结束后，在「本轮修改」中展开「全部修改」，查看文件与增删行数；可打开单文件编辑器对比，或用「查看总 Diff」打开 VS Code 多文件对比视图。

「撤回本轮修改」在确认后恢复完整采集的普通文本内容与权限。文件必须仍与本轮结束快照一致，相关编辑器不能有未保存内容；不覆盖后续修改，也不回退聊天记录和模型上下文。采集范围、预算与撤回风险见[每轮修改汇总](turn-diff.md)。

## 模型、思考强度与 Fast

输入框附近的选择器显示当前 Agent 实际提供的模型与思考选项。新会话读取该 Agent 最近成功使用的模型 / thinking 组合，跨工作区共享；恢复已有会话则保留该会话自身设置。Pi 桌面与 Telegram 共用服务端偏好。

Pi 使用 OpenAI / Codex Responses 时可提供 Fast mode，请求 `priority` 服务；它与思考强度独立，默认关闭，可能增加费用，是否可用取决于模型、账户与扩展支持。设置随 Pi 原生会话及分支恢复，不作为新会话的全局默认。其他 Agent 的 Fast 选项取决于适配器。

### 模型设置

右上角「模型设置」管理模型可见性、价格和 Pi context 长度；统计表中可点击的模型名也可打开此页。

- 模型按供应商分组，支持搜索，以及供应商级全部显示、隐藏和恢复默认。
- 模型标题旁的勾选控制其在输入框模型列表中的可见性。
- 每个模型可设置输入、输出、缓存读取、缓存写入四项单价；用户价格优先于 Pi 返回的默认价格，缺少价格时显示未定价。
- Pi context 输入单位为 k tokens，例如 256 表示 256000 tokens。「保存 / 恢复默认」同时应用四项价格与 context 值。其他 Agent 暂不支持修改 context。
- context 修改写入 Pi 配置目录的 `models.json`，与 Pi 共用，需要已连接且空闲的会话；不会提高供应商真实上下文上限。
- 打开页面、刷新配置及发送下一轮前会重新读取 Pi 模型配置；运行中的任务不会因此切换模型，思考强度与 Fast 保持不变。冷会话也能刷新模型目录，不发送模型提示词。

用量记录、标题和会话编号只读写扩展宿主账户的全局文件 `~/.pi/pi-acp-workbench/preferences/usage.json`，同一主机、同一账户下跨工作区和 VS Code Profile 共享；不再读取或回写 workspaceState，也不迁移旧工作区记录。文件不存在时从空统计开始。Remote SSH 使用远端扩展宿主账户的文件，不与本机或其他主机自动同步。价格、可见性和所选 Agent 也存在扩展宿主账户的 `~/.pi/pi-acp-workbench/preferences/`；模型 / thinking 由 daemon 保存到其数据目录下的 `preferences/{pi,codex,claude}.json`。

### 自动会话命名

Pi 新会话收到首条文本后，可先调用模型生成约 8–16 字标题。模型设置中的「会话名压缩模型」可选择指定 Pi 模型、跟随当前模型或关闭；默认跟随当前模型，配置由服务保存。

命名只发送首条输入的前 1000 个字符，不加载项目上下文，不调用工具，不进入聊天记录，也不改变聊天模型。服务最多等待 20 秒，失败保留短文本标题，不自动重试或批量重命名已有会话。此调用会产生少量额外模型费用，返回用量纳入统计。标题跨重启保留，并用于桌面和 Telegram。

## 用量统计与上下文

「用量统计」支持按模型、时间、会话查看 token 与费用估算。时间视图提供天 / 周（周一开始）/ 月费用柱状图，沿用日期筛选；会话以 `#编号 会话名` 标识。

- 只统计具有有效 Workbench 会话编号的记录，排除外部 Pi 会话；总计与各视图使用同一过滤范围，不删除原始记录。
- 默认价格读取 Pi 返回的模型配置；更新 Pi 或价格后刷新统计即可使用最新默认价，自定义价格优先。
- Codex / Claude 依赖适配器返回输入、输出和缓存用量，只记录启用后经本服务执行的轮次，不回填原生历史。缺失数据与未知模型会明确提示。
- 上下文条使用 Agent 上报的当前占用与窗口大小，不用累计 token 推算。长任务中会刷新并保存到会话快照。
- Pi `/compact` 成功后只显示压缩成功，不显示内部摘要；上下文占用等待下一次模型回复后更新。

用量与价格可能不完整，估算不代表订阅额度或供应商最终账单。

## Pi 后台任务扩展

支持 `pi-better-background-tasks` 等扩展在后台任务完成后自主唤醒 Pi。完成消息与后续回复显示在对话中，支持忙碌状态、停止、工具授权、历史保存与 Telegram 完成通知。

- 扩展需安装在 daemon 实际启动的 Pi 环境中；TUI 专用 navigator / widget 不会移植到侧栏。
- 自主轮次运行时不接收用户输入，也不将其排为 follow-up 或 steering。抢先唤醒导致的发送失败会明确标记，保留输入供手动重试，不自动重发，也不中断自主输出或授权。
- 后台任务唤醒后的自主输出作为独立轮次显示，不会把上一轮最终回答或「本轮修改」重新折入执行过程；忙碌时仅隐藏当前轮次的消息操作按钮。轮次标识随会话快照保存。旧快照中未记录的后台轮次边界不自动推断或回填。
- 自主轮次支持工具级 Diff，但不额外采集整轮工作区 Diff 基线。
- 更新内置适配器后，需在任务空闲时更新并重启会话服务，让 worker 加载新适配器。

## 连接与排障

默认 socket 为 `~/.pi/pi-acp-workbench/service/sessions.sock`；通过 `piAcp.serviceSocket` 指定其他路径后重新加载窗口。服务未启动时会报连接错误，插件不会直接启动 Agent。

- 检查服务：`systemctl --user status pi-sessions`。
- 查看服务日志：`journalctl --user -u pi-sessions -f`。
- 查看插件日志：命令面板执行 **Pi: Show Agent Logs**。
- 认证：命令面板执行 **Pi Workbench: Open Current Harness Login Terminal**，或在服务账户终端使用对应 CLI 登录。

服务 PATH、代理、容量与恢复说明见[会话服务](session-service.md)。日志可能含私人代码或凭据，分享前请脱敏。
