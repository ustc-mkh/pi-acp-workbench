# 每轮修改汇总

每轮输出末尾显示「本轮修改」卡片，与工具调用的单步 diff 分开。支持 Pi、Codex、Claude Code；三种 harness 的采集和保存均由独立服务负责，关闭桌面不会中断采集。

- 文件列表放在默认折叠的「全部修改」中，可一次展开或收起所有文件；显示文本新增/删除行数以及文件类型/权限变化。
- 文件列表显示摘要；「在编辑器中对比」按需从服务加载该轮开始/结束的只读文本。旧 inline 快照仍可展开查看补丁。
- 「查看总 Diff」直接打开 VS Code 原生多文件对比视图，使用本轮开始/结束的只读文本快照，支持新增、修改和删除。未保存完整文本的文件会提示跳过，具体原因在卡片中查看。
- 「撤回本轮修改」经模态确认后，恢复卡片中普通文本文件的本轮前内容和权限，删除本轮新增文件、恢复本轮删除文件。仅完整快照可用；聊天记录与模型上下文不回退。
- 空结果和采集范围说明直接显示，不再放入「改动说明」折叠项。
- 同一文件多次修改只显示开始到结束的净变化；改完再还原不会留下虚假的修改。
- 成功、取消、Agent 进程失败都会尽量生成结果；快照保存后重新打开仍可查看。
- Telegram 完成通知带文件/行数汇总；不自动推送完整补丁正文。

## 采集范围

基线是**本轮实际 prompt 执行前的工作区内容**，不是 HEAD 或暂存区。因此此前未提交的修改不会作为本轮新增修改重复出现。使用 Git 枚举会话工作目录下已跟踪文件及未被忽略的未跟踪文件，包含通过 shell 修改的文件，不依赖工具是否发送 ACP diff。

采集时不执行 `git add`、checkout、reset、commit 或 stash，不修改用户的 Git index、工作树或提交历史。对比来自私有临时文本副本，Git 外部 diff/textconv 被禁用；正常结束清理临时目录。符号链接仅对比链接文本，不读取其目标；工作区外目录不会被跟随读取。Diff 本身是界面元数据，不会作为新 prompt 发送，也不会改变 Pi 原生上下文。

## 限制必须明确

- 需要 Git 工作区和可执行的 `git`。非 Git 目录显示「未能采集」，不会把整个目录当成新增修改。
- 最多枚举 5000 个文件；单文件文本上限 1 MiB，每次快照文本预算 16 MiB，本轮详细内容预算 4 MiB。超过限制、二进制、非 UTF-8、子模块或读取失败会标注部分/不可用结果，不声称完整。
- 行数只统计成功生成的文本补丁。二进制和省略文件不计入文本行数。
- Webview 每个文件最多预览 400 行/约 30000 字符，按展开动作延迟创建 DOM；编辑器可查看已保存的完整补丁。
- 只读快照不是文件系统事务。同一目录内同时进行的手工编辑或其他会话修改也可能计入；采集时发生变化的文件会尽量标为未完整采集。
- 重命名显示为删除/新增；任务改变忽略规则时，新出现的文件可能是之前被忽略的文件，会显示提示。
- ignored 文件、工作目录外的写入以及任务完成后仍运行的后台程序修改不在保证范围内。
- 服务自身崩溃/断电时，尚未生成的最终 diff 不会事后猜测重建；应检查实际文件与原生历史。

保存的 diff 可能包含源码和敏感内容，内容文件为 0600。历史删除后，不可达正文在下次正常启动清理，不承诺即时安全擦除。它是审阅记录，不提供文件回滚保证。

## 手动撤回的边界

- 撤回需要受信任工作区及配套 v4 daemon，不再依赖扩展宿主 Git；当前任务输出/连接期间不可操作。确认窗口期间，客户端会话门控阻止并发发送或切换。
- 确认前及确认后均检查文件：必须仍与本轮结束快照一致，删除的文件必须仍不存在，相关编辑器不得有未保存内容。发现冲突时不开始写入；不会强制覆盖后续修改。
- 不完整快照、二进制、省略内容、符号链接、硬链接、特殊文件/特殊权限、越界路径及 `.git` 路径不能撤回。
- 客户端只发送会话及条目 ID；daemon 从已提交历史加载完整 before/after，不执行 patch 字符串。使用非跟随目录描述符检查路径，按快照字节数有界读取；暂存文件以 0600 创建，发布前设置最终普通权限并 fsync，然后 rename/unlink，不修改 Git index。恢复缺失父目录时使用 0700，不猜测目录原权限。
- 只恢复卡片中采集到的净变化；忽略文件、工作区外写入及模型内部状态不在范围内。同轮并发手工或其他会话修改也可能包含在快照中，确认前应先审阅 Diff。
- daemon 按真实目录对撤回授予独占许可，与所有客户端发起的同目录/父子目录任务互斥；冲突明确拒绝。普通任务之间仍可并行。此锁不覆盖外部编辑器或任务遗留的后台进程。
- 这不是多文件原子事务。检查与发布之间仍无法排除外部写入，磁盘错误或崩溃可能导致部分恢复。撤回经过 durable 请求收据，不自动重放；错误后应检查工作区。详情见 [持久化与恢复](persistence-recovery.md)。

## 实现与验证

采集与预算位于 `rust/crates/pi-acp-session-daemon/src/diff.rs`，轮次保存由 `service/turn.rs` 完成。客户端字段定义在 `src/turn-diff.ts`，展示由 `webview/messages.ts` 负责；打开编辑器对比由 `src/conversation-attachments.ts` 与 `src/workspace-documents.ts` 协调。

撤回逻辑位于 `rust/crates/pi-acp-session-daemon/src/undo.rs`，目录协调位于 `workspace_gate.rs`，正文分离存储位于 `history/diff_content.rs`。Rust undo 与 `turn-undo-coordinator` 测试覆盖内容/权限恢复、有界读取、冲突拒绝、路径边界、未保存编辑、确认取消及会话切换；rust-sessions 覆盖真实服务撤回及同 ID 防重放。Rust diff 单测在临时 Git 仓库验证采集，rust-sessions 回归验证正常 / 取消 / 崩溃后持久化，messages 与浏览器冒烟验证展示。统一运行入口见 [测试指南](testing.md)。快照字段及权限见 [磁盘格式](data-formats.md)。
