## 跨切片必须保持的断言

1. query 不写 operation、不启动 worker；attach/dispatch 同一短快照；提交后新查询可见。
2. 本地 mutation 状态与 terminal receipt 同事务；相同 ID 不同指纹冲突；收据过期不使 ID 可再执行。
3. 外部 configure/fork/撤回/topic 有 prepare/settle 和 uncertain；SIGKILL 前后不重试未知副作用。
4. 先 commit 后 publish，revision CAS，epoch/turn fence，worker 物理 join；取消 observer 不取消已接受写入。
5. Telegram durable offset/分类/接受边界、发送后 ack 前崩溃、multipart/429/rebind/remove；同 topic head 不越过、独立 ready topic 不饿死。
6. 删除分别定义单会话、全历史、归档、待投递、native 文件；全历史入口必须范围预览和二次确认，不静默 reset root。
